 ##  Curso de Python - Curso em Vídeo

Repositório criado para organizar e documentar todos os exercícios, desafios e projetos práticos desenvolvidos por mim durante o renomado **Curso de Python** do professor Gustavo Guanabara, na plataforma **Curso em Vídeo**.

O objetivo deste projeto é consolidar meus conhecimentos em lógica de programação, estruturas de dados e desenvolvimento de scripts com a linguagem Python.

---

## 🚀 Tecnologias e Ferramentas Utilizadas

* **Python 3** (Linguagem principal)
* **VS Code** (Ambiente de desenvolvimento / IDE)
* **Git & GitHub** (Controle de versão e hospedagem do código)
* **Jupyter Notebook (`.ipynb`)** (Utilizado para testes interativos no Mundo 3)
* **Venv** (Ambiente virtual para isolamento de dependências, quando necessário)

---

## 📚 Estrutura do Curso

O curso é dividido em 3 grandes blocos (Mundos), que vão do básico absoluto até estruturas complexas e modularização:

### 🌍 Mundo 1: Fundamentos de Python
Conceitos iniciais da linguagem, instalação de ferramentas, operações aritméticas, manipulação de textos e estruturas condicionais simples.
* [x] Exercícios de 001 a 035.
* **Principais conceitos:** Tipos primitivos, operadores, manipulação de strings (`split`, `join`), estruturas condicionais (`if/else`).

### 🪐 Mundo 2: Estruturas de Controle
Aprofundamento em condições e introdução às estruturas de repetição e loops.
* [x] Exercícios de 036 a 071.
* **Principais conceitos:** Condições aninhadas (`elif`), estruturas de repetição `for` e `while`, interrupção de loops com `break`.

### 🌌 Mundo 3: Estruturas Compostas
Exploração de coleções de dados avançadas, funções, tratamento de erros e criação de módulos.
* [ ] Exercícios de 072 a 89 (ainda n terminei mundo 3).
* **Formatos:** Notebooks Interativos (`.ipynb`) — ideal para visualizar estruturas de dados complexas passo a passo.
* **Principais conceitos:** Tuplas, Listas,  Dicionários, Funções (`def`), Modularização (Pacotes) e Tratamento de Erros/Exceções.

## 🛠️ Como Executar os Códigos

Para rodar qualquer um dos scripts na sua máquina, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/ViniciusOLopes/Curso-de-Python.git
   ```

2. **Entre na pasta do projeto:**
   ```bash
   cd Mundo1
   cd Mundo2
   cd Mundo3
   ```

3. **Execute o script desejado:**
   ```bash
   python 'Nome do arquivo'.py
   ```
### 🔹 Para os Jupyter Notebooks (Mundo 3)
1. Certifique-se de que a extensão **Jupyter** está instalada no seu VS Code.
2. Ative o seu ambiente virtual (`venv`) para garantir as dependências do Kernel.
3. Abra o arquivo `.ipynb` desejado diretamente no VS Code.
4. Execute célula por célula clicando no botão de *Play* ao lado de cada bloco de código.
